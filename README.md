# byxin

The marketplace for **byxin-grounded**: ByxIn's brain inside Claude Code. Grounded answers checked against what was
shown, an honest record of what happened, and one shared brain for every Claude Code session in a project.

```
/plugin marketplace add hendrikusjohannes92-cell/byxin-grounded
/plugin install byxin-grounded@byxin
```

Everything about the plugin, including exactly what it runs, sends and stores, is in
[plugins/byxin-grounded/README.md](plugins/byxin-grounded/README.md). BSD-2-Clause.
